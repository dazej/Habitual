# This is a extension of a course project that I assisted with and designed. 
It is Habit Tracking App with the ability to track milestones, different habits, and completions of habits. 

I plan to grow this app to become a social media habit tracking where you can grow with your friends and encourage 
friendly competitions and supporting communities for all types of goals. 

This project uses Spring Boot, Java, and SQL currently as only the backend has been completed.
